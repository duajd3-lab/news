📌 프로젝트 소개

Today’s Insight는 실시간 뉴스 데이터를 기반으로
사용자에게 트렌드 뉴스와 주요 이슈를 직관적인 UI로 제공하는 뉴스 플랫폼입니다.

모바일 환경에 최적화된 인터페이스와
실시간 트렌드 랭킹 시스템을 통해 뉴스 소비 경험을 개선했습니다.
